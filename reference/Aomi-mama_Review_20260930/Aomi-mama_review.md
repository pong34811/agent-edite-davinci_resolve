## สิ่งที่ตรวจจริงและข้อจำกัด

- ตรวจโครงสร้างทั้ง 16 Timeline: 8 แนวนอน 1920×1080 และ 8 แนวตั้ง 1080×1920 ทั้งหมด 60 fps
- เรนเดอร์พรีวิวครบ 16 Timeline ตรวจไฟล์ว่ามีภาพและเสียงและความยาวตรงกับ Timeline ทุกไฟล์ ผ่านการตรวจความครบของไฟล์

## เสียงที่วัดได้

ตัวเลขของคู่แนวนอน/แนวตั้งตรงกันถึงทศนิยมที่รายงาน ไม่ได้เปลี่ยนมิกซ์ในรอบรีวิว

| เรื่อง | Integrated loudness | True peak |
|---|---:|---:|
| เกมแรก | -16.3 LUFS | -6.4 dBFS |
| น้ำหนักน่ายก | -16.1 LUFS | -1.0 dBFS |
| เรื่องราว | -19.1 LUFS | -1.3 dBFS |
| จบไลฟ์ | -18.2 LUFS | -1.1 dBFS |
| RoV | -17.0 LUFS | -1.2 dBFS |
| ไม่เสียใจ | -13.8 LUFS | -1.2 dBFS |
| เป้าหมาย | -16.5 LUFS | -1.2 dBFS |
| หนอนแมลง | -13.9 LUFS | -1.2 dBFS |

- ไม่พบยอด true peak เกิน 0 dBFS จากการวัดไฟล์พรีวิว
- ความดังรวมต่างกันมากสุดประมาณ 5.3 LU จึงอาจรู้สึกดังเบาต่างกันเมื่อดูต่อกัน
- ตัวเลขนี้ไม่ยืนยันว่าไม่มีเสียงแตกจากต้นทาง หรือ SFX/BGM ไม่กลบคำพูด ต้องฟังจริงก่อนผ่านขั้นสุดท้าย
- ไม่มีการกำหนดแพลตฟอร์ม loudness target ใหม่หรือปรับเสียง เพราะผู้ใช้สั่งรักษาระดับเสียงเดิม

## ฟอนต์ที่ยังต้องตรวจให้จบ

- ฟอนต์หลักของแทร็กที่มีซับได้รับการตั้ง Mitr Bold ตามงานก่อนหน้า
- Text+ ของ RoV ทั้งสองเวอร์ชันอ่านจากข้อมูลโปรเจกต์ได้เป็น Mitr Bold
- พบข้อมูล rich text เฉพาะคำในซับบางชิ้นยังบันทึก Open Sans อยู่ การเปลี่ยนฟอนต์ระดับแทร็กอย่างเดียวจึงยังไม่ใช่หลักฐานว่าทุกคำใช้ Mitr Bold แล้ว ต้องตรวจและแก้เฉพาะคำโดยรักษาสีและสไตล์อื่น
- ฟอนต์ Bold อย่างเดียวไม่ได้แก้ปัญหาข้อความล้น ขนาดเล็ก หรือสีตัวอักษรกลืนกับพื้นหลัง

## ลำดับงานที่เสนอ

1. แก้ข้อบกพร่องภาพก่อน: เฟรมแนวตั้งกลับเป็นแนวนอน/พื้นที่ดำ, แชตใหญ่, ภาพประกอบถูกตัด
2. แก้การอ่านซับ: เป้าหมายล้นขอบ, หนอนแมลงกับ RoV เล็ก, ฟอนต์เฉพาะคำที่ยังค้าง
3. ฟังจริงให้ครบด้วยลำโพงมือถือหรือหูฟัง ตรวจเสียงพูด/SFX/BGM ทุกคลิป
4. หากอนุมัติให้ปรับเนื้อหา จึงทำจุดเปิดและจังหวะใหม่ โดยเริ่ม “น้ำหนักน่ายก” และ “เกมแรก” ก่อน
5. ส่งตัวอย่างหนึ่ง Timeline ให้ดู แล้วค่อยทำที่เหลือ ตามวิธีทำงานที่ผู้ใช้ระบุ

การปรับจุดตัด ความยาว สไตล์ซับ หรือเสียงที่เป็นข้อเสนอในรายงานนี้ยังไม่ได้ดำเนินการ
