# Subagent Delegation Pattern for Thumbnail Concepts

Source: davinci-thumbnails SKILL.md §Procedure ขั้นตอนที่ 2, hermes-agent skill (delegation).

## 4 บทบาท (หนึ่ง `delegate_task` call, 4 sub-tasks)

1. **Target Audience & Identity** — กลุ่มผู้ชม, จุดยืน, บุคลิก/เอกลักษณ์, เหตุผลที่จำได้
2. **Landscape 16:9 Concept** — คอนเทนต์แนวนอน, hook, โครงสร้างองค์ประกอบ
3. **Portrait 9:16 Concept** — คอนเทนต์แนวตั้ง/Shorts, hook เปิดคลิป, อ่านบนจอเล็ก
4. **Independent Reviewer** — ความแตกต่าง, สอดคล้อง, ผลิตได้จริง, ความเสี่ยง, เกณฑ์ทดสอบ

## Rules

- บริบทเดียวกัน ขอบเขตต่างกัน — ส่งผลลัพธ์พร้อมเหตุผล, กลุ่มผู้ชม, รูปแบบ, ตัวอย่างหัวข้อ, ภาพจำตัวละคร, สมมติฐาน
- ห้ามอ้างข้อมูล YouTube ปัจจุบันโดยไม่มีแหล่งอ้างอิง
- ผู้ช่วยหลักรับผิดชอบความถูกต้อง — รายงานผู้ช่วยย่อยเป็นข้อเสนอ ไม่ใช่หลักฐาน
- สังเคราะห์: เลือกแนวคิดหลักหนึ่ง, รวมจุดแข็ง, ตัดซ้ำ, ระบุความเห็นต่าง

## Output Schema (ส่งกลับมาให้หลักสังเคราะห์)

- สมมติฐาน/เป้าหมาย
- Hook 1 ประโยค + เอกลักษณ์ VTuber
- ผู้ชมเป้าหมาย + เสาหลักคอนเทนต์
- แนวนอน: รูปแบบ + แนวปก
- แนวตั้ง: Shorts ออกแบบใหม่ + hook ต้นคลิป
- เชื่อมคลิปยาวกับ Shorts (ตัดต่อใหม่ ไม่ครอปทื่อ)
- ขั้นทดลอง + ตัวชี้วัด
- ขั้นถัดไป + ความเสี่ยง

## Hermes Tooling

- `delegate_task(goal=..., context=..., toolsets=[...], role="leaf")` — ส่งงานย่อย
- `skill_view(name="davinci-thumbnails")` — อ่านขั้นตอนการทำปกเต็มรูปแบบ
- `skill_view(name="vtuber-thumbnail-qc")` — QC ปกหลังทำเสร็จ (บังคับ)

## When NOT to Use Delegation

- ขอเพียงแผน → ส่งแผนแล้วหยุด ไม่สร้างชิ้นงาน
- งานง่าย/แก้ไขเล็กน้อย → ทำเอง inline
- ไม่มี `delegate_task` → แจ้งข้อจำกัด อย่าอ้างว่าเรียกครบ
