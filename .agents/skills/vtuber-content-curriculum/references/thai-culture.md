# Thai Culture (Topic 14)

## 14. Thai Humor & Internet Culture

**Core principle:** Thai humor is context-dependent — what works may not translate directly.

**Thai humor types:**
| Type | Description | Example |
|---|---|---|
| Wordplay | Puns and double meanings | คำพ้องเสียง, คำผสม |
| Slang | Casual/internet language | เหยียด, แอโร่, มุ้งมิ้ง |
| Reaction | Exaggerated responses | อุทาน, หัวเราะ, ทำหน้า |
| Situational | Context-dependent comedy | เข้าใจผิด, สถานการณ์แปลก |
| Self-deprecating | Making fun of oneself | ขี้เกียจ, เซ่น, โง่ |
| Parody | Imitating for comedy | ล้อเลียง, เลียนแบบ |

**Thai internet culture elements:**
- **Stickers:** LINE stickers are ubiquitous in Thai chat culture
- **Emoji:** 555 (55555 = หัวเราะ), 🙏, 😂, 😭
- **Memes:** Thai-specific memes (rare, often localized)
- **Language mixing:** Thai-English code-switching is common
- **Politeness:** ครับ/ค่ะ particles reflect gender and formality

**Application in editing:**
- Preserve Thai humor — don't translate jokes that rely on language
- Use Thai internet slang naturally in captions and titles
- Reference Thai cultural moments when relevant
- Don't force humor that doesn't fit the VTuber's personality
- Respect cultural sensitivities

**Chat culture:**
- Thai viewers use stickers, emojis, and short messages
- Chat speed reflects engagement level
- Highlight funny chat messages as overlays
- Preserve chat language — don't translate or censor

**Regional considerations:**
- Thai VTuber audience is primarily Thai-speaking
- International fans may need context for cultural references
- Balance accessibility with authenticity

**For agents:**
- Learn Thai internet slang from context, not dictionaries
- When uncertain about humor, flag for human review
- Don't assume Western humor translates to Thai context
- Study the VTuber's community for cultural norms
