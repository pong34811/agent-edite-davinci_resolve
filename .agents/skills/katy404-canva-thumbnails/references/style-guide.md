## สิ่งที่เห็นซ้ำในตัวอย่าง

- ตัวละครหลักผมสีเงินอมฟ้า ตาโทนเหลืองทองในภาพที่ลืมตา เสื้อสีดำและรายละเอียดชมพู หลายหน้าเป็นครึ่งตัวถือไมโครโฟน มีขอบขาวแยกจากฉาก บางหน้าเป็นชิบิ
- ภาพเกมเต็มพื้นที่ บางหน้ามืดหรือเบลอเพื่อให้อวาตาร์และข้อความเด่น มีทั้งภาพจากเกมและฉากภาพประกอบ
- ข้อความไทยหนา ทรงค่อนข้างมน สีขาว เส้นขอบดำหนา ไม่ได้ยืนยันชื่อฟอนต์หรือค่าความหนาขอบจากข้อมูลเลเยอร์
- ตัวอย่างบางหน้ามีคำร้องหรือคำเน้นสีแดง เช่น “ช่วยด้วย” ส่วนข้อความอธิบายเป็นสีขาว ตามคำสั่งล่าสุดของผู้ใช้ ให้ใช้ Mitr Bold ขอบดำกับข้อความทั้งหมด โดยทำ hook หลักบรรทัดใหญ่เป็นสีแดง และข้อความรองเป็นสีขาว
- วิเคราะห์ hierarchy ก่อนจัดวาง: เลือก hook หลักเพียงหนึ่งคำหรือวลีให้ใหญ่/เด่นกว่า แล้วให้ข้อความรองอธิบายบริบทด้วยขนาดที่เล็กลง เช่น “ช่วยด้วย” เป็น hook หลักสีแดง ส่วน “ติดที่เดียวกัน” เป็นข้อความรองสีขาว
- เครื่องหมาย ? ! สีหน้าอวาตาร์ หัวเพื่อนแบบวงกลม และวงกลมสีแดงช่วยเล่าเหตุการณ์ ไม่จำเป็นต้องใส่ทุกอย่างพร้อมกัน
- ปกคลิปแนวนอนหลายหน้าวางอวาตาร์ใหญ่ด้านขวา ข้อความอยู่ซ้ายล่างหรือช่วงล่าง หน้ารูปแบบพิเศษไม่จำเป็นต้องมีอวาตาร์
- ปก Shorts ใช้แนวภาพกลาง บ่อยครั้งอวาตาร์อยู่ล่างและ hook อยู่เหนือศีรษะ ภาพหน้า 86 และ 171 เป็นใบหน้าขนาดใหญ่เด่นเกือบเต็มเฟรม

สีที่กล่าวถึงเป็นการสังเกตด้วยตาจาก preview ไม่ใช่ brand token ที่วัดแล้ว หากต้องสร้างสีใหม่ให้เทียบกับภาพจริง แต่การแก้สำเนาควรเก็บสีเดิม

## เลือกหน้าให้เข้ากับเรื่อง

### Shorts แนวตั้ง

- หน้า 3–4: หน้าตัวละครใหญ่ด้านล่าง ข้อความอยู่ช่วงกลางบน เหมาะกับ reaction หนึ่งเหตุการณ์
- หน้า 5: หัวเพื่อนบน ตัวละครหลักล่าง และ hook คั่นกลาง เหมาะกับบทสนทนา
- หน้า 6: คำเน้นสั้นเหนือ hook อวาตาร์ล่าง เหมาะกับสถานการณ์วุ่นวาย; ให้ hook หลักสีแดงและข้อความรองสีขาว
- หน้า 86/171: ใบหน้าขนาดใหญ่และ hook เด่น เหมาะเมื่อสีหน้าเป็นประเด็นสำคัญ ตรวจข้อความหรือของตกแต่งที่อาจฝังในภาพด้วย
- อย่าตัดขอบปกแนวนอนเพื่อทำแนวตั้งโดยตรง เลือกหน้าคู่กันจากคอลเลกชัน Shorts แล้วจัดจุดเด่นใหม่ โดยจัดข้อความ hook และข้อความรองกึ่งกลางตามแนวนอน และวางโมเดล/อวาตาร์กึ่งกลางแนวนอนบริเวณครึ่งล่าง เว้นแต่ผู้ใช้กำหนดตำแหน่งอื่น

### LIVE แนวนอน

- หน้า 5: แนวเรียบ ใช้ภาพเกม อวาตาร์ใหญ่ด้านขวา hook ล่างซ้าย และป้าย LIVE บนซ้าย เหมาะเป็นโครงตั้งต้นของเกมเพลย์ทั่วไป
- หน้า 6: โทนทอง/ส้ม อวาตาร์ขวา ข้อความหนาเฉียงขาว+เหลือง ใช้เมื่อเหมาะกับเกมและอารมณ์ ไม่บังคับให้ทุกงานสดใส
- หน้า 1: Minecraft แบบภาพประกอบชิบิ มี LIVE ชื่อเกม เลขตอน และข้อความรอง เหมาะกับซีรีส์ที่มีข้อมูลครบ ตรวจว่าข้อความอยู่ในเลเยอร์ใด
- หน้า 2–3: ชิบิผจญภัย สีฟ้า เหลือง ชมพู เส้นขอบและรูปทรงสนุก ใช้เมื่อผู้ใช้เลือกแนวนี้ ตรวจภาพแบน/ข้อความฝังเป็นพิเศษ
- หน้า 34: ทีมตัวละครเกมและ hook ซ้ายล่าง ไม่มีอวาตาร์ช่องเป็นภาพเด่น อย่าเพิ่มอวาตาร์เพียงเพราะหน้าอื่นมี
- หน้า 4 มีภาพสี่เหลี่ยมวางทับองค์ประกอบเดิมและพื้นที่ขาว ดูเหมือนยังจัดไม่เสร็จ จึงไม่ใช้เป็นต้นแบบค่าเริ่มต้น
- หน้า 68 ไม่มีป้าย LIVE ให้เห็นใน preview แม้อยู่ในคอลเลกชัน LIVE อย่าอนุมานว่าทุกหน้ามีป้ายพร้อมใช้

## คำแนะนำจัดวางสำหรับงานใหม่

ข้อต่อไปนี้เป็นแนวทางตั้งต้น ไม่ใช่ค่าที่วัดจาก Canva หรือข้อบังคับของแพลตฟอร์ม:

- แนวนอน: ให้อวาตาร์กินพื้นที่ประมาณ 35–50% ของความกว้างเมื่อใช้โครงอวาตาร์ขวา เก็บจุดเกิดเหตุและ hook ในฝั่งที่เหลือ ปรับตามภาพจริง
- แนวตั้ง: ให้ใบหน้าและ hook อยู่ในแกนกลางของภาพ เลี่ยงข้อความชิดขอบและพื้นที่ส่วนควบคุมของแพลตฟอร์ม หากต้องรองรับหลาย crop ให้ดู preview ของแต่ละ crop
- ไม่กำหนด safe zone แพลตฟอร์มจากความจำ ถ้าต้องส่งตามข้อกำหนดแพลตฟอร์มล่าสุดให้ตรวจข้อมูลหรือหน้าจอปัจจุบัน
- เริ่มด้วย hook 1–2 วลีสั้น/1–2 บรรทัด ขนาดอ่านได้บนจอเล็กสำคัญกว่าจำนวนคำตายตัว โดยเฉพาะภาษาไทยที่ไม่ได้เว้นวรรคทุกคำ
- ถ้าฟอนต์ เอฟเฟกต์ หรือกรอบใหม่สร้างด้วย API ไม่ได้ ให้รักษา native style เดิมและเลือกหน้าที่เหมาะกับความยาวข้อความ แทนการลดคุณภาพเพื่อเลียนแบบด้วยภาพแบน

### ใช้แนวทาง VTuber ทั่วไปเป็นข้อมูลประกอบ

- อย่าบังคับแบ่งภาพ 50/50 หรือใช้ตัวละครครึ่งตัวทุกครั้ง รูปแบบ KATY404 มีทั้งภาพใบหน้าใหญ่ ชิบิ และบางหน้าที่ไม่มีอวาตาร์

## สิ่งที่ไม่ควรติดมาจากต้นแบบ

อย่าเก็บชื่อเพื่อน ตัวเลข subscriber เลขตอน วันที่ คำพูด โลโก้เกม หรือฉากเก่าเพียงเพราะอยู่ในสำเนา ตรวจทั้งข้อความแก้ไขได้และข้อความใน bitmap ไม่คัดลอกคำสะกดผิดจากตัวอย่างเป็นกติกา และอย่ารับประกันยอดคลิกจากการใช้สไตล์นี้
