# house-style Skill Reference

House style editorial and finishing preferences:
1. Subtitle track only: create dialogue captions only on native Subtitle tracks (not Text+). Keep short-form Thai captions <= 3 short words, <= ~14 chars, <= 1.5s per cue. No spaces between Thai words.
2. Rejected by default: titles, captions, text cards, transitions, effects/speed ramps, music beds, grading on assembly cuts.
3. Save project after mutations and verify exact state.
