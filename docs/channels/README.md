## กติกาการใช้และการอัปเดต

- ข้อมูลในโปรไฟล์มาจากหลักฐานใน repo, memory ของ agent และการดูโฟลเดอร์ต้นทางแบบอ่านอย่างเดียว ไม่ใช่การตรวจ Resolve สด ต้องยืนยันชื่อโปรเจค/timeline/IDs จาก Resolve ทุกครั้งก่อนเขียน
- หัวข้อ "ยังไม่ทราบ" คือสิ่งที่ต้องถามผู้ใช้ อย่าเดา และเมื่อได้คำตอบให้ย้ายขึ้นไปหัวข้ออื่น
- จบงานของช่องไหน ให้เสนอและบันทึก learning ที่มีหลักฐานในโปรไฟล์ช่องนั้นตาม `.agents/skills/project-learning/SKILL.md`; อย่าแต่งข้อมูลเมื่อไม่มีบทเรียน
- กฎที่ใช้กับทุกช่อง (ซับ ≤14 ตัวอักษร ≤1.5 วิ, โครงสร้าง track ฯลฯ) อยู่ใน `AGENTS.md` และ `house-style` ไม่ต้องคัดลอกมาที่นี่

## บันทึกความจำและ evidence รายช่อง

- ใช้โปรไฟล์ตาม index เฉพาะช่องที่ระบุ; ไม่ยืม profile, preset หรือบทเรียนจากช่องอื่นโดยไม่มีหลักฐาน หากช่องไม่ชัดหรือข้อมูลขัดกันให้ถามผู้ใช้ ไม่เดา กฎร่วมอยู่ใน `house-style`.
- บันทึกวันที่, project/timeline ID หรือเอกสารอ้างอิง, กฎ/สิ่งที่พบ, สถานะ, ขอบเขต applicability, ผู้ยืนยัน และลิงก์ evidence ที่ตรวจย้อนกลับได้โดยไม่เปิดเผยข้อมูลลับ หากไม่มีผู้ยืนยันให้ระบุว่าไม่มี ไม่แต่งชื่อ
- `confirmed` ใช้เฉพาะสิ่งที่ผู้ใช้ยืนยันหรือหลักฐานที่ตรวจจริง และระบุว่าใครหรืออะไรยืนยัน; `hypothesis` คือข้อสันนิษฐานที่ต้องตรวจต่อ ไม่ใช่ข้อบังคับตัดต่อหรือความชอบที่ผู้ใช้ยืนยันแล้ว; เมื่อหลักฐานขัดแย้งให้เก็บประวัติและแหล่งเดิม ระบุ `superseded` พร้อมเหตุผลและลิงก์ไปข้อใหม่ ไม่ลบประวัติ ถ้ายังตัดสินไม่ได้ให้คง conflict และถามผู้ใช้
- Privacy: ห้ามใส่ credentials, transcript, footage หรือข้อมูลส่วนตัวในบันทึกหรือลิงก์ที่เปิดเผย; ห้ามส่ง footage เสียง transcript หรือข้อมูลส่วนตัวไป provider ภายนอกโดยไม่มีขอบเขตและการอนุญาตชัดเจน ใช้การอ้างอิงที่ปลอดภัยและเข้าถึงได้ตามสิทธิ์แทน

**ตัวอย่างสมมติเท่านั้น (ไม่ใช่ข้อมูลช่องจริง):** วันที่ 2026-01-01; เอกสารอ้างอิง `example-review.md` (สมมติ); ข้อพบ: ทดลองซับสั้น; สถานะ `hypothesis`; applicability: คลิปตัวอย่างเท่านั้น; ผู้ยืนยัน: ไม่มี; evidence: อ้างอิงเอกสารสมมติ ไม่ใช่ลิงก์จริง.
