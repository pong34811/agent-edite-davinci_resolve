# การคัดคลิป Vtuber ไทย

เป้าหมายคือหาช่วงจากไลฟ์ที่ผู้ใช้ระบุ เพื่อนำไปตัดเป็นคลิปสั้นลง YouTube ไม่ถือว่าคะแนนจากเอเจนต์ยืนยันผลการเผยแพร่ได้ ([brief ผู้ใช้](../../raw/2026-10-04-user-project-brief.md), “ต้นฉบับ”; ส่วนคะแนนด้านล่างเป็นข้อเสนอของเอเจนต์)

## หมวดที่ใช้ในงาน

| หมวดใน pipeline | สิ่งที่มองหา ตาม prompt |
| --- | --- |
| `gameplay` | ช่วงเล่นเกมตึงเครียด เก่ง หรือขำ พร้อมคำพูดคอมเมนต์ |
| `fun` | พูดคุยเล่น ปฏิสัมพันธ์กับผู้ชม และปฏิกิริยา |
| `meme` | ประโยคติดหู มุกซ้ำ หรือปฏิกิริยาที่ตัดแยกเป็นคลิปได้ |

อ้างอิง [prompt](../../raw/2026-10-04-project-prompt.md), “นิยามหมวด” คำ `funny` ใน brief ใช้สื่อแนวเนื้อหา แต่คีย์ข้อมูลปัจจุบันคือ `fun` ไม่เปลี่ยนชื่อ field ของ pipeline โดยอัตโนมัติ

## เกณฑ์จัดอันดับทดลอง — ยังไม่ผ่านการสอบเทียบ

ตารางนี้เป็น **ข้อเสนอของเอเจนต์** สำหรับเปรียบเทียบผู้สมัครในงานเดียวกัน ไม่ใช่ preference ที่ผู้ใช้ยืนยัน ไม่ใช่สูตรทำนายยอดวิว ให้คะแนน 0–2 เฉพาะด้านที่ตรวจหลักฐานแล้ว หากยังไม่ตรวจให้เป็น `unverified` และไม่รวมคะแนนเพื่อจัดอันดับเด็ดขาด

| ด้าน | 0 | 1 | 2 |
| --- | --- | --- | --- |
| จุดดึงความสนใจ | ยังไม่พบเหตุการณ์ชวนติดตาม | ต้องปูเรื่องก่อนจึงเห็นประเด็น | มีคำพูด/เหตุการณ์ชวนติดตามตั้งแต่ช่วงต้นที่เลือก |
| ความเข้าใจเมื่อแยกจากไลฟ์ | ต้องพึ่งบริบทที่ไม่มีในช่วง | เข้าใจได้เมื่อขยายบริบท | เข้าใจเหตุและผลได้ภายในคลิป |
| จุดจบ/มุก/ผลลัพธ์ | ไม่มีบทสรุปที่ตรวจพบ | มีบทสรุปแต่ยังตัดไม่ลงตัว | มี payoff ที่ชัดและจบครบ |
| เอกลักษณ์ Vtuber | ยังไม่พบสิ่งจำเพาะในช่วง | มีปฏิกิริยาหรือคำพูดเฉพาะบางส่วน | บุคลิก/ปฏิกิริยาหรือการโต้ตอบเป็นใจกลางเหตุการณ์ |
| ความพร้อมตัดต่อ | หลักฐาน/ภาพเสียงยังไม่พร้อม | ใช้ได้แต่ต้องแก้จุดตัดหรือขยายช่วง | ภาพเสียงใช้ได้และจุดเริ่ม–จบครบตามข้อจำกัดงาน |
| ความต่างจากผู้สมัครอื่น | ซ้ำเหตุการณ์ที่เลือกแล้ว | มีส่วนใหม่แต่ยังทับกัน | มีเหตุการณ์ใหม่ที่แยกได้ชัด |

คะแนนรวมเต็ม 12 ใช้เรียงลำดับช่วยพิจารณาเมื่อครบทุกด้าน และต้องแสดงเหตุผลพร้อมเวลาเหตุการณ์ ไม่กำหนดคะแนนผ่านตายตัว จำนวนคลิปและข้อจำกัดงานให้ใช้ prompt ปัจจุบันก่อนเสมอ

## หลักฐานก่อนเลือก

ข้อเสนอนี้ต่อยอดจากขั้นอ่านเสียง/ถอดเสียง/ภาพตัวอย่างใน [prompt](../../raw/2026-10-04-project-prompt.md), “วิธีวิเคราะห์”:

- transcript ช่วยตามเรื่องและหาประโยค แต่ไม่พิสูจน์ภาพหรือความแม่นยำของ ASR
- ดู/ฟังช่วงจริงเพื่อตรวจคำพูด ภาพ ปฏิกิริยา setup และ payoff ก่อนระบุว่าเป็นผู้สมัครที่ยืนยันแล้ว
- เก็บชื่อไฟล์ `source_id` เวลาในต้นฉบับ และ offset หากดูไฟล์ตัดย่อย
- ความดังใช้หาช่วงเบื้องต้น ระวังเสียงเกมที่ดังแต่ไม่มีเรื่อง และมุกเสียงเรียบที่อาจตกหล่น ข้อหลังถูกระบุใน [prompt](../../raw/2026-10-04-project-prompt.md), “ความเสี่ยง”
- ระยะเวลาและ aspect ใช้ค่าจริงของงาน อย่าแปลงทุกคลิปเป็นแนวตั้งเพียงเพราะเป็นคลิปสั้น

## ข้อสังเกตจากงานจริงรอบแรก (agent-observed, 2026-10-04)

จากรอบ [Hoshi 2026-10-03](../analyses/hoshi-2026-10-03-run.md) เป็นข้อสังเกตของเอเจนต์จากงานเดียว ไม่ใช่กฎที่ผู้ใช้ยืนยัน:

- ถอดเสียงเฉพาะช่วงที่คัดจากเสียงได้ราวครึ่งหนึ่งของฟุตเทจ ขณะที่ผู้ใช้อนุมัติชุดคลิปที่ได้ ไม่ได้พิสูจน์ว่าช่วงที่ไม่ได้คัดไม่มีคลิปที่ดีกว่า
- ชื่อไฟล์ไม่ใช่ตัวบอกเนื้อหา: ให้จัดหมวดจาก transcript และภาพ แล้วตรวจสื่อจริงก่อนยืนยัน
- ข้อความ ASR ภาษาไทยของไลฟ์เหล่านี้เพี้ยนและมีข้อความหลอน มุกและคำพูดที่อ้างจาก ASR ต้องถือว่ายังไม่ยืนยัน และควรให้ผู้ตรวจระบุคลิปที่มั่นใจต่ำเพื่อให้ผู้ใช้ฟังก่อนใช้
- รอบนี้ยังไม่ได้ใช้ตารางเกณฑ์ทดลองข้างบน จึงไม่มีหลักฐานว่าเกณฑ์ช่วยเพิ่มคุณภาพ
