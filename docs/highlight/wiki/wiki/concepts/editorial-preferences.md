# รสนิยมการตัดต่อที่ยืนยันแล้ว

## แหล่งกฎ

หัวข้อเนื้อหาที่ผู้ใช้ระบุคือ Vtuber ไทย ไลฟ์ gameplay funny และ meme ([brief](../../raw/2026-10-04-user-project-brief.md), “ต้นฉบับ”)

กฎการตัดต่อด้านล่างมาจาก skill ที่มีอยู่ ไม่ใช่การอนุมาน preference เพิ่มเติมของเอเจนต์ ([house-style](../../raw/2026-10-04-house-style.md), “Capture protocol”)

| ขอบเขต | กฎที่มีอยู่ | ที่มา |
| --- | --- | --- |
| rough-cut | assembly โดยไม่เพิ่มข้อความ/ซับ/เอฟเฟกต์/เพลง/เกรด ยกเว้น brief สั่ง | house-style: Rejected by default |
| งานซับไทย | วลีสั้นตามจังหวะพูด สูงสุดสามคำสั้น ประมาณ 14 ตัวอักษร ไม่เกิน 1.5 วินาที | house-style: Pacing and rhythm |
| feedback | เก็บ preference ที่ใช้ซ้ำได้เป็น Rule / Why / Trap | house-style: Capture protocol |

หลักฐาน: [ต้นฉบับ house-style](../../raw/2026-10-04-house-style.md), หัวข้อในคอลัมน์ “ที่มา” งานปัจจุบันต้องตรวจไฟล์ skill ที่ใช้งานจริงอีกครั้ง

## ยังไม่ยืนยัน

ยังไม่มีเกณฑ์ที่ผู้ใช้ยืนยันว่าควรเลือกมุกแบบไหน เปิดคลิปอย่างไร หรือให้ตัดตรงไหน หมวดดังกล่าวยังว่างใน skill ดังนั้นใช้ [เกณฑ์คัดคลิปทดลอง](clip-selection.md) เป็นข้อเสนอและเก็บ feedback แยกจากกฎที่ยืนยัน ([ต้นฉบับ](../../raw/2026-10-04-house-style.md), “Shot selection”, “Cut points”, “Structure and openings”)
