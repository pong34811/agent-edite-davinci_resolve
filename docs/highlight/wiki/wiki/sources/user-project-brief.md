# เป้าหมายโปรเจกต์จากผู้ใช้

ผู้ใช้ต้องการให้วิกิช่วย skill ของโปรเจกต์ค้นหาช่วงจากวิดีโอที่ระบุ เพื่อนำไปตัดเป็นคลิปสั้นลง YouTube โดยเน้น Vtuber ไทย ไลฟ์ gameplay funny และ meme ([ต้นฉบับ](../../raw/2026-10-04-user-project-brief.md), หัวข้อ “ต้นฉบับ”)

## การตีความและสิ่งที่ยังไม่ระบุ

เอเจนต์ตีความ “cilp virus” ว่าหมายถึงคลิปที่มีโอกาสไวรัล คำนี้ยังไม่ได้รับการยืนยันเป็นนิยามจากผู้ใช้ ไม่มีการระบุยอดวิวเป้าหมายหรือเกณฑ์ความสำเร็จ ([ต้นฉบับ](../../raw/2026-10-04-user-project-brief.md), “ต้นฉบับ”)

ข้อความนี้ไม่ได้ยืนยันว่าจะใช้ YouTube Shorts โดยเฉพาะ ไม่ได้เปลี่ยนอัตราส่วนภาพ ระยะเวลา หรืออนุญาตการอัปโหลด ให้ใช้ brief ของงานจริงก่อนดำเนินการ ([ต้นฉบับ](../../raw/2026-10-04-user-project-brief.md), “ต้นฉบับ”; ดู [ตัวแปรโปรเจกต์](project-prompt.md))
