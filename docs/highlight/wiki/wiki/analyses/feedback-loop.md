# เรียนรู้จากคลิปที่เลือกและปฏิเสธ

## เป้าหมาย

ทำให้การคัดรอบถัดไปใช้ feedback ที่มีหลักฐาน แทนการตีความใหม่จากศูนย์ ข้อกำหนดเดิมให้บันทึกคำแก้ที่ใช้ซ้ำได้ลง house-style ([prompt](../../raw/2026-10-04-project-prompt.md), ข้อความท้าย “สิ่งที่ต้องส่งมอบ”; [house-style](../../raw/2026-10-04-house-style.md), “Capture protocol”)

## ขั้นตอนเสนอโดยเอเจนต์

1. งานจริงบันทึก candidate ใน `WORK_DIR` ตามรูปแบบ pipeline แล้วเลือกเฉพาะบันทึกที่มีประโยชน์มาเป็นหน้าวิเคราะห์ของวิกิ ใช้ [แม่แบบ clip review](../../templates/clip-review.md)
2. ผูกทุกผลกับช่อง งาน ไฟล์จริง เวลาในต้นฉบับ setup/payoff และหลักฐานที่ตรวจแล้ว แยกความเห็นเอเจนต์ออกจากคำตอบผู้ใช้
3. เมื่อผู้ใช้เลือก ปฏิเสธ หรือขอแก้ ให้เก็บคำตอบและเหตุผลที่ระบุ หากไม่ให้เหตุผลให้บันทึกว่าไม่ทราบ ห้ามเดาว่าไม่ชอบเพราะเหตุใด
4. เพิ่มกฎ house-style เฉพาะเมื่อผู้ใช้ระบุ preference ที่ใช้ซ้ำได้ เก็บ Rule / Why / Trap และลิงก์บริบทในวิกิ การปฏิเสธหนึ่งคลิปไม่เท่ากับห้ามคลิปหมวดนั้น
5. ถ้ามีผล YouTube จริง เก็บ video identifier วันที่เผยแพร่ วันเก็บข้อมูล ช่วงเวลา และ metric ตามข้อมูลที่ได้รับ อย่าใส่เลขประมาณ เปรียบเทียบเมื่อช่วงเวลาและบริบทเหมาะสมเท่านั้น
6. ทบทวนเกณฑ์ทดลองจากหลายงาน บันทึกว่าปรับอะไรเพราะหลักฐานใด ไม่ประกาศความสัมพันธ์เชิงเหตุจากยอดวิวอย่างเดียว

ข้อ 1 อิงสิ่งส่งมอบใน [prompt](../../raw/2026-10-04-project-prompt.md), “สิ่งที่ต้องส่งมอบ”; ข้อ 4 อิง [house-style](../../raw/2026-10-04-house-style.md), “Capture protocol”; การเชื่อมข้อมูลและการประเมินข้ออื่นเป็นข้อเสนอ ยังไม่ผ่านการทดสอบกับงานจริง

## สถานะหลักฐาน

ณ 2026-10-04 มี feedback จริงหนึ่งรอบ: ผู้ใช้อนุมัติ 31 คลิปของงาน Hoshi 2026-10-03 โดยไม่ระบุเหตุผลรายคลิป ([คำตอบผู้ใช้](../sources/user-approval-31-clips.md), “สิ่งที่ผู้ใช้ระบุ”; รายละเอียดงานใน [บันทึกรอบงาน](hoshi-2026-10-03-run.md)) การอนุมัติทั้งชุดบอกไม่ได้ว่าชอบเกณฑ์ใดหรือคลิปใดดีกว่า จึงยังไม่เพิ่มกฎ house-style และยังไม่มีผลเผยแพร่หรือ analytics ที่ยืนยันว่าคลิปเหล่านี้ได้ผลดี
