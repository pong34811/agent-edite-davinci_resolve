# สารบัญวิกิ

สารบัญหน้าความรู้ทั้งหมด ปรับปรุงเมื่อมีการเพิ่มหรือเปลี่ยนหน้า

## ภาพรวม

- [ภาพรวมวิกิ](overview.md) — โปรเจกต์คัดคลิป Vtuber ไทย ขอบเขต หลักฐาน และคำถามเปิด

## แหล่งข้อมูล

- [เป้าหมายจากผู้ใช้](sources/user-project-brief.md) — แนว Vtuber ไทย ไลฟ์ gameplay funny และ meme สำหรับคลิป YouTube
- [Prompt โปรเจกต์](sources/project-prompt.md) — workflow คัดคลิป/Resolve และข้อจำกัด ณ วันที่นำเข้า
- [House style](sources/house-style.md) — กฎ rough-cut งานซับ และการเก็บ preference ที่มีอยู่
- [คำตอบและการอนุมัติ 31 คลิป](sources/user-approval-31-clips.md) — ค่าที่ผู้ใช้เลือกและการอนุมัติ 31 คลิปของ Hoshi 2026-10-03 โดยไม่ระบุเหตุผลรายคลิป

## แนวคิดและเอนทิตี

- [การคัดคลิป Vtuber ไทย](concepts/clip-selection.md) — หมวด หลักฐาน และเกณฑ์จัดอันดับทดลอง
- [รสนิยมการตัดต่อ](concepts/editorial-preferences.md) — กฎที่มีหลักฐาน แยกจาก preference ที่ยังไม่ยืนยัน

## การวิเคราะห์

- [วิกิช่วย skill อย่างไร](analyses/skill-integration.md) — จุดอ่านวิกิร่วมกับ skill และสิ่งที่ต้องตรวจสด
- [เรียนรู้จากคลิปที่เลือก/ปฏิเสธ](analyses/feedback-loop.md) — เก็บ feedback และผลจริงกลับมาปรับงานถัดไป
- [บันทึกรอบงาน Hoshi 2026-10-03](analyses/hoshi-2026-10-03-run.md) — ผล pipeline จริง 31 คลิป แยกค่าผู้ใช้ ตัวเลขที่วัดได้ และข้อจำกัดของ ASR

## การใช้งาน

- [คู่มือ](../README.md) — วิธีนำเข้า ถามคำถาม และตรวจสุขภาพวิกิ
- [บันทึกการทำงาน](log.md) — ประวัติการตั้งค่า นำเข้า ถามคำถาม และบำรุงรักษา
- [กฎสำหรับเอเจนต์](../AGENTS.md) — รูปแบบหน้าและข้อกำหนดเรื่องหลักฐาน
