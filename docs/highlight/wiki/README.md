# LLM Wiki

วิกิความรู้ที่เอเจนต์ช่วยสรุป เชื่อมโยง และอัปเดตจากแหล่งข้อมูลที่คุณเลือก เก็บเป็น Markdown และเปิดอ่านได้ใน Obsidian

ตอนนี้กำหนดสำหรับโปรเจกต์คัดคลิป Vtuber ไทยจากไลฟ์ gameplay funny และ meme ลง YouTube เริ่มที่ [วิกิช่วย skill อย่างไร](wiki/analyses/skill-integration.md) และ [เกณฑ์คัดคลิป](wiki/concepts/clip-selection.md) ทางเชื่อมสำหรับเอเจนต์อยู่ใน [AGENTS.md ของโปรเจกต์](../../../AGENTS.md)

เริ่มอ่านที่ [สารบัญ](wiki/index.md) ดูขอบเขตและคำถามค้างที่ [ภาพรวม](wiki/overview.md) และดูประวัติที่ [บันทึกการทำงาน](wiki/log.md)

## เริ่มใช้งาน

1. เปิดโฟลเดอร์ `docs/highlight/wiki` (เดิมชื่อ `llm_wiki`) เป็น vault ใน Obsidian
2. วางต้นฉบับลงใน `raw/` เช่น Markdown, ข้อความ, PDF หรือ transcript ส่วนภาพประกอบเก็บใน `raw/assets/`
3. สั่งเอเจนต์ตามตัวอย่างด้านล่าง เอเจนต์จะอ่าน [AGENTS.md](AGENTS.md) และอัปเดตวิกิให้
4. อ่านหน้าสรุป ตรวจการอ้างอิง แล้วบอกเอเจนต์ว่าควรเน้นหรือแก้ประเด็นใด

หากเริ่มเอเจนต์จากโฟลเดอร์โปรเจกต์ภายนอก vault ให้ระบุให้ชัดว่าอ่าน `llm_wiki/AGENTS.md` ก่อนทำงาน

## ตัวอย่างคำสั่ง

**นำเข้าแหล่งข้อมูล** — หลังวางไฟล์จริงใน `raw/`:

> อ่าน llm_wiki/AGENTS.md แล้วนำเข้า llm_wiki/raw/article.md สรุปประเด็นหลักพร้อมอ้างอิง อัปเดตหน้าที่เกี่ยวข้อง สารบัญ และ log

**ตั้งขอบเขต**:

> ตั้งวิกินี้สำหรับศึกษาหัวข้อ [หัวข้อที่ต้องการ] และปรับ overview ให้สะท้อนเป้าหมายกับคำถามที่ฉันอยากรู้

**ถามและเก็บคำตอบ**:

> จากข้อมูลในวิกิ แนวคิด A กับ B ต่างกันอย่างไร? อ้างอิงต้นฉบับและบันทึกคำตอบเป็นหน้าวิเคราะห์

**ถามโดยไม่สร้างหน้าวิเคราะห์**:

> ตอบในแชทเท่านั้น: มีแหล่งข้อมูลอะไรบ้างที่พูดถึงหัวข้อนี้?

**ตรวจสุขภาพวิกิ**:

> ตรวจสุขภาพ llm_wiki: ลิงก์เสีย หน้าที่ตกสารบัญ ข้ออ้างที่ไม่มีหลักฐาน ความขัดแย้ง และข้อมูลล้าสมัย แก้สิ่งที่มีหลักฐานรองรับแล้วบันทึกผลใน log

## โครงสร้าง

| ตำแหน่ง | หน้าที่ |
| --- | --- |
| `raw/` | ต้นฉบับที่ไม่แก้ไขหลังบันทึก |
| `wiki/sources/` | สรุปแต่ละแหล่งข้อมูลและลิงก์กลับต้นฉบับ |
| `wiki/concepts/` | หัวข้อ แนวคิด บุคคล และองค์กร |
| `wiki/analyses/` | การสังเคราะห์ เปรียบเทียบ และคำตอบที่เก็บไว้ |
| [index.md](wiki/index.md) | สารบัญเนื้อหาทั้งหมด |
| [overview.md](wiki/overview.md) | ขอบเขต ภาพรวม และช่องว่างความรู้ |
| [log.md](wiki/log.md) | ประวัติแบบเพิ่มท้ายไฟล์ |
| [AGENTS.md](AGENTS.md) | กฎการดูแลวิกิสำหรับเอเจนต์ |
| `templates/` | แม่แบบ [แหล่งข้อมูล](templates/source.md), [หัวข้อ](templates/concept.md), [การวิเคราะห์](templates/analysis.md) |
| [clip-review.md](templates/clip-review.md) | บันทึกหลักฐานผู้สมัครคลิป ความเห็นเอเจนต์ feedback ผู้ใช้ และผลเผยแพร่จริง |

นำเข้า brief ผู้ใช้และสำเนา prompt/house-style แล้ว ยังไม่มีผลวิเคราะห์ฟุตเทจหรือ analytics ของคลิปในวิกิ ข้อมูลตัวอย่างในแม่แบบไม่ใช่ข้อเท็จจริง ระบบนี้ใช้คำสั่งของคุณเพื่อให้เอเจนต์ทำงาน ไม่มีตัวเฝ้าโฟลเดอร์หรือการนำเข้าอัตโนมัติ
