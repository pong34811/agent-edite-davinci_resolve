# ชื่อแหล่งข้อมูล

> แม่แบบเท่านั้น: แทนวันที่ ชื่อ และข้อมูลด้วยค่าจริงก่อนสร้างหน้า เพิ่ม path ต้นฉบับใน sources และ source_path ค่า coverage ใช้ complete เมื่ออ่านครบหรือ partial พร้อมระบุส่วนที่ขาด ลิงก์ด้านล่างต้องสร้างตามไฟล์จริง

## ที่มาและขอบเขตที่อ่าน

ระบุผู้เขียน วันที่เผยแพร่ ประเภทเอกสาร และส่วนที่อ่านได้ เชื่อมกลับต้นฉบับด้วยลิงก์ relative จากหน้าสรุป

## สรุป

สรุปใจความของแหล่งข้อมูล โดยแยกสิ่งที่ผู้เขียนกล่าวออกจากการตีความของเอเจนต์

## ประเด็นสำคัญและหลักฐาน

แต่ละข้อมีลิงก์ต้นฉบับและตำแหน่ง เช่น หัวข้อ หน้า PDF หรือ timestamp

## ข้อจำกัดและความขัดแย้ง

ระบุข้อจำกัดของแหล่งข้อมูลและสิ่งที่ขัดกับข้อมูลเดิม พร้อมลิงก์หลักฐานทั้งสองฝั่ง

## หน้าที่เกี่ยวข้อง

ลิงก์ไปหน้าหัวข้อ/การวิเคราะห์ที่ได้รับการอัปเดต และสารบัญ
