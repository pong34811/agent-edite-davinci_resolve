# ชื่อคลิปและงาน

> แม่แบบเท่านั้น: กรอกจากงานจริงและผูกหลักฐาน ห้ามเติมเวลาหรือเหตุการณ์จากการเดา จัดเก็บหน้าใหม่ใน wiki/analyses/ และลงสารบัญ sources ชี้หลักฐานที่มีอยู่จริงใน vault; อาร์ติแฟกต์นอก vault ให้ลิงก์ในเนื้อหา

## ที่มาคลิป

- ช่อง / JOB / candidate id / source_id:
- ชื่อไฟล์ต้นฉบับและ path หรือ identifier ที่ตามกลับได้:
- fingerprint ถ้ามี:
- ช่วง in/out ในวิดีโอต้นฉบับและความยาว:
- หน่วยเวลา / fps ถ้าใช้เฟรม:
- offset หากอ่าน transcript หรือดูวิดีโอตัดย่อย:
- หมวดตาม prompt ปัจจุบัน:

## เหตุการณ์และหลักฐาน

- setup / hook / payoff พร้อมเวลาในต้นฉบับ:
- สิ่งที่ตรวจจากภาพและเสียงจริง:
- ข้อความ ASR ที่ยังไม่ยืนยัน:
- ลิงก์ transcript / เฟรม / report ที่มีอยู่จริง:

## ความเห็นเอเจนต์

เหตุผลคัดเลือก ข้อจำกัด และคะแนนทดลองแต่ละด้านหากตรวจครบ คะแนนไม่ใช่ความน่าจะเป็นไวรัล

## คำตอบผู้ใช้

- ผล: pending / selected / rejected / revise
- วันที่และคำตอบหรือเหตุผลที่ผู้ใช้ระบุ:
- ถ้าไม่ให้เหตุผล ระบุว่าไม่ทราบ:

## สิ่งที่ใช้ซ้ำได้

แยกการแก้เฉพาะคลิปจาก preference ที่ผู้ใช้ระบุให้ใช้ต่อ หากเป็นกฎถาวรให้บันทึก Rule / Why / Trap พร้อม provenance

## ผลการเผยแพร่ ถ้ามีหลักฐานจริง

video identifier / วันที่เผยแพร่ / วันเก็บข้อมูล / ช่วงวัด / metric จากข้อมูลจริง ไม่รู้ให้เว้นหรือระบุไม่ทราบ

## หน้าที่เกี่ยวข้อง

เพิ่มลิงก์ไปหน้าคัดคลิป รสนิยม วงจรเรียนรู้ และสารบัญ ตามตำแหน่งของหน้าที่สร้าง
